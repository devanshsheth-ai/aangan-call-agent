Aangan call agent: component map

Trigger, input, context, processing, AI, output. One phone call, followed from ring to designer inbox.

1 · Trigger

A call comes in

  • Caller dials the studio number, any hour.
  • Vaani AI answers, asks 7 short questions, books a consultation slot.
  • Vaani fires call_started then call_postprocessing to our webhook.
2 · Input

Webhook payload

  • POST /api/vaani/webhook?token=… (Vaani does not sign webhooks, so the secret is in the URL; compared in constant time).
  • Phone number and start time from call_started.
  • Transcript string [hh:mm:ss] AGENT/USER: …, summary, duration (ms, may be missing), recording URL from post-processing.
3 · Context

What the AI is allowed to know

  • knowledge/qualified.md: Nikhil's five criteria.
  • knowledge/services.md: what the studio does and does not do.
  • pricing.md is never loaded. It is not in the repo, not bundled, not in any prompt.
4 · Processing

Next.js on Vercel + Neon

  • Upsert the call row; if already classified, return "duplicate" (idempotent).
  • Atomic claim so two retries never process the same call twice.
  • Call length derived from start → end when Vaani omits it; after-hours flag (outside 10am–7pm IST).
  • Route to a designer: segment match, then fewest leads in the last 7 days.
5 · AI

Gemini Flash classification

  • JSON mode, low temperature, transcript treated as untrusted text.
  • Returns qualifiednot_fitcomplaintunclear, the deciding criterion, asked_pricing, segment, lead fields, an 8-line handoff note.
  • Price filter in code strips any per-sq-ft, rate or estimate line from the AI output. A caller's own budget passes through.
  • Booked slot only from an explicit caller acceptance, validated to a sane date window.
6 · Output

Independent, best-effort

  • Qualified: designer email (Resend) with Claim / Reschedule / booking link, and a HubSpot deal.
  • Complaint: front-desk email, a human handles it.
  • Not fit / unclear: logged only.
  • Dashboard: calls, after-hours, qualified, booked, show-ups, won, cost (voice + AI), price slips.

The Cut: the agent never quotes a price

Three layers: (1) the voice prompt forbids it, (2) pricing.md is never given to any model, (3) a code filter removes price lines from everything the AI writes, and flags any agent turn that quoted one (shown as "price slips" on the dashboard). Asking about price never disqualifies a caller. Pricing is Nikhil's call, by design.

What happens when something breaks

FailureResult
Gemini down or returns junkRaw transcript is emailed to the front desk and the call is logged as "unclear". The lead is never lost.
Database downRaw transcript is emailed to the front desk, webhook returns 500, Vaani retries.
Designer email failsThe same email goes to the front desk instead.
HubSpot fails or is offLogged on the call row; designer email still goes out.
Vaani retries a webhookAlready classified: ignored. Being processed right now: ignored. Stuck for 5 minutes: re-claimed.
Email scanner clicks a linkGET only shows a confirm page. Nothing is recorded until a person presses the button (POST).
